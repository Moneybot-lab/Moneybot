# Alpha Atlas integrity assessment

**Disposition.** No direct provider call was found in Alpha Atlas scoring, probability estimation, calibration, feature generation, ranking, portfolio ledger accounting, drawdown calculations or V4 certification. Quick Ask consumes an existing decision. Unlocked Portfolio advice can change a displayed action **and the recommendation stored in a general-purpose research event**. The latter requires independent quantitative validation before a model substitution or change to fallback behavior. Production incidence, inclusion in actual training runs and any change in realized returns are unverified.

## Verification and release gate

The audit has no baseline-file changes. Git object identity for the entire audited base tree is the preservation reference. The manifest records the base tree and a reproducible digest covering its tracked paths and blob identities. The audit uses the repository's checksum convention on new audit documents only.

For a later authorized migration, carry forward the original base, compare all protected blobs and existing manifest checksums byte-for-byte, and fail on any unapproved delta. Use synthetic fixed outputs at the deterministic boundary, including blocked/absent states. Compare locked actions, threshold decisions, probabilities (including null), prediction IDs, calibration metadata, evidence inclusion, ledger outputs and fallback provenance. Require zero differences in protected outputs. Use only synthetic/mocked market and LLM inputs. Validation must not execute real V4 scoring, rerun closed investigations, regenerate historical datasets, or overwrite evidence to obtain matching results.

For unlocked cases, the quant owner must approve a separate comparison of action confusion matrices, BUY/SELL flips, missing-data decisions and research-row eligibility. Publish sample sizes, disagreements and acceptance disposition. A prospective model is ineligible for this lane until that decision is recorded. Preserve original rows and existing pass/fail definitions. [Validation plan](openai_migration_validation_plan.md)
